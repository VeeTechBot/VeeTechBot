// FPGA Subsystems

Custom CPU Core
Purpose-built processor architecture in Verilog on Cyclone IV FPGA. Handles instruction decode, data flow, and concurrent sensor + motor control — all running as hardware logic.

Motor Control
Dual DC motor drive with PWM signals generated directly from FPGA GPIO pins. Differential drive enables precise turning and wall-following within narrow maze corridors.

// 4-Layer PCB · DD Robocon 2026 · IIT Delhi
Actuator + Interface Board
Modular Robot Electronics — First-Try Bring-Up

My first 4-layer PCB — and it worked perfectly on its very first bring-up. Every year at DD Robocon the robot changes — new sensors, new microcontrollers, new control strategies — but the core electronics stay the same. So instead of redesigning from scratch each season, we built a modular two-board system: a fixed Actuator Board and a detachable Interface Board that plugs in like an Arduino shield. Every SMD component on the board, down to the fine-pitch ICs, was hand-soldered in-house by the team.

// Design & Assembly Highlights
  • Designed a 4-layer PCB end-to-end in Altium — schematic capture, layout, and manufacturing files
  • Architected a modular two-board system: a fixed Actuator Board plus a detachable, shield-style Interface Board — so the controller can be swapped season to season without touching the power/actuation layer
  • Routed dedicated channels for 10 DC motor drivers, servo interfaces, and pneumatic relay control, alongside on-board power regulation and distribution
  • Hand-soldered every SMD component in-house with the team — fine-pitch ICs down to passives
