// Electronic Subsystems
🚗
Drive Control
4× BLDC hub motors in skid-steer layout. Independent ESC per wheel enables tank-style pivot and omnidirectional movement at 20–30 km/h.

Telemetry & Comms
Dual 433 MHz Holybro modules for UGV ↔ laptop link. Range extendable to km-scale with patch antennas. Handles drive + mechanism commands.
⚙️
Mechanism Control
Planetary DC motors via Cytron MDD20A for mine/mud-drop. Nema 34 steppers via TB6600 for precision lead-screw auger positioning.
📹
Video Transmission
SpeedyBee TX800 5.8 GHz on-board. Skydroid OTG receiver at operator station. RunCam Phoenix 2 for front and mine-drop monitoring.
⚡
Power Distribution
13S LiFePO4 20 Ah as main bus. XT60 parallel bus for ESCs. Fixed 12 V/10 A bucks × 2 parallel for actuators. Variable bucks for MCU logic.
🖥️
Interface Board
Custom in-house PCB with Teensy 4.1 at centre. All ESC channels, stepper driver headers, telemetry UART, relay for VTX, I2C PWM expander.

// FPGA Robotics · Autonomous Navigation · IIT Bombay
MazeSolver Bot
e-Yantra Robotics Competition 2025–26

An FPGA-powered autonomous robot built from scratch for the e-Yantra Robotics Competition (eYRC 2025–26), hosted by IIT Bombay under the Ministry of Education. Running on a De0-Nano board with Altera Cyclone IV, the robot navigates dynamic warehouse-like mazes in real time while measuring environmental parameters — temperature, humidity, and soil moisture — at designated arena zones.

  • Designed and implemented a custom CPU architecture on FPGA fabric using Verilog HDL on the De0-Nano board (Altera Cyclone IV EP4CE22F17C6)

  • Integrated Capacitive Soil Moisture Sensor v1.2 for analog zone readings, enabling environmental data logging at warehouse waypoints

  • Designed HC-SR04 ultrasonic sensor drivers in Verilog for multi-directional obstacle detection and wall-following behavior
  • Implemented UART serial communication module in Verilog for wireless transmission of environmental readings to the Central Control Unit
  • Assembled the complete robot hardware from e-Yantra kit components — chassis, motor mounts, sensor brackets, and wiring harness
  • Ranked among Top 50 teams nationally, qualifying for the hardware kit distribution phase with a De0-Nano FPGA board
  • Competed through all phases of the competition — simulation, hardware build, and arena — earning a Level 3 Certificate of Participation from IIT Bombay

// FPGA Subsystems
🧠
Custom CPU Core
Purpose-built processor architecture in Verilog on Cyclone IV FPGA. Handles instruction decode, data flow, and concurrent sensor + motor control — all running as hardware logic.
🌡️
Environmental Sensing
DHT11 1-wire driver reads temperature and relative humidity. Capacitive soil moisture sensor v1.2 logs zone moisture levels. Data packetized and transmitted at designated arena waypoints.
🗺️
Maze Navigation
HC-SR04 ultrasonic sensors on front and sides. Verilog FSM maze-solving algorithm processes sensor inputs in real time, adapting to dynamically reconfigured warehouse wall layouts.
⚙️
Motor Control
Dual DC motor drive with PWM signals generated directly from FPGA GPIO pins. Differential drive enables precise turning and wall-following within narrow maze corridors.
🔄
Parallel Processing
FPGA fabric runs sensor acquisition, navigation FSM, motor control, and UART communication fully in parallel — a true hardware concurrency advantage over microcontroller architectures.
📶
Serial Communication
Custom UART TX/RX module in Verilog. Environmental sensor data packetized and sent wirelessly to the Central Control Unit. Verified in ModelSim before hardware deployment.
